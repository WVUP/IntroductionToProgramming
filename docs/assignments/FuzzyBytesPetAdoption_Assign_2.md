# Fuzzy Bytes Pet Adoption - Assignment

## Dog Class
1.	Create a class called Dog with the following instance variables and data types (in parentheses):
- name (String)
- age (int)
- breed (String)
- weight (double)
- isHouseTrained (boolean) 
- personality (String) 
- isHypoallergenic (boolean)
- isAdopted (boolean)
2.	Create a default constructor for the Dog class that sets all variables equal to zero, false, or an empty String where appropriate.

3.	Create an overloaded constructor for the Dog class assigning each instance variable the value coming from a parameter.
